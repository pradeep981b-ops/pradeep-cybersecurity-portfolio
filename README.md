## Run Locally

### Prerequisites

- Node.js 18 or newer
- npm

### Installation

Clone the repository or download the project, then open its project directory in your terminal.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```

The production build is generated in the `dist/` directory. It can be deployed to a supported static hosting platform.
